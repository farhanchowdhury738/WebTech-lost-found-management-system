# Khoja-Khuji — Lost & Found Management System

A web-based Lost & Found Management System built with **PHP, MySQL, HTML, and CSS**, following the **MVC (Model–View–Controller)** architecture.

## Features

* User Registration & Login
* Report Lost Items
* Report Found Items
* Search & Category Filtering
* View Item Details
* Claim Found Items
* User Profile Management
* Admin Management


## Project Structure

```text
Khoja-Khuji/
├── Controller/
├── Model/
├── View/
├── assets/
├── uploads/
├── database.sql
└── README.md
```

## Technologies

* PHP
* MySQL
* HTML
* CSS
* XAMPP
* MVC Architecture

## Run Locally

1. Install **XAMPP**.
2. Start **Apache** and **MySQL**.
3. Copy the project into:

```text
C:\xampp\htdocs\
```

## Purpose

This project was developed for **educational purposes** to demonstrate PHP, MySQL, MVC architecture, CRUD operations, authentication, and collaborative software development.
